# Infinity Orbs v1.2.55

## Combat
- Reworked Speed cadence so each side starts with one action ready, then earns further actions by accumulating Speed. The Delver no longer gets a guaranteed attack on every beat; higher Speed earns actions sooner and can earn multiple actions in one beat.
- Combat Orb rolls now use neutral 1× Luck. Main-game Luck and Luck bonuses do not influence combat Orb rarity.
- The combat Orb panel now shows realized damage from all player hits in the latest beat, alongside the Orb's base damage.

## Discoveries and enemies
- Expanded the named Orb pool for every rarity tier, including large finite rarities.
- Added eighteen enemy archetypes with distinct names, rooms, and Speed/damage profiles.
